E-Commerce Sales & Customer Analysis using SQL
## 📌 Project Overview

This project analyzes e-commerce sales and customer data using SQL to understand sales performance, customer behavior, product performance, and business trends.

## 🛠️ Tools Used

* SQL / MySQL
* Excel
* Data Cleaning
* Exploratory Data Analysis
* Business Analysis

## 📁 Dataset

The dataset contains e-commerce sales and customer information used to perform SQL-based business analysis.

Key areas analyzed include:

* Customer information
* Product details
* Sales transactions
* Revenue
* Order trends

## 🔧 Project Workflow

### 1. Data Exploration

* Reviewed the dataset structure
* Checked missing values and duplicates
* Examined important business fields

### 2. Data Cleaning

* Handled missing and invalid records
* Removed duplicate records where required
* Standardized data for analysis

### 3. SQL Analysis

Used SQL queries to analyze:

* Sales and revenue trends
* Customer purchasing behavior
* Product performance
* Top-performing products and categories
* Business trends

## 📊 Business Insights

The analysis was used to identify:

* Top-performing products and categories
* Customer purchasing patterns
* Sales and revenue trends
* Areas with potential business opportunities

## ▶️ How to Run

1. Download or clone this repository.
2. Open the SQL file in MySQL.
3. Import the dataset.
4. Run the SQL queries to reproduce the analysis.

* `project.sql` — SQL queries and analysis
